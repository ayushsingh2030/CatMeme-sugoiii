# CatMeme-sugoiii

A real-time meme pose and action matcher.

Users upload memes, start their webcam, then recreate facial expressions, hand gestures, or body poses. The app detects the closest matching meme and displays it live.

## Planned MVP

- Upload multiple memes
- Webcam preview
- Face, hand, and pose landmark detection
- Landmark-based meme matching
- Smooth real-time switching between matches
